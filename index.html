Credit Card Fraud Detection Using Deep Learning

A deep learning neural network built to detect fraudulent credit card transactions, formulated as a binary classification problem. The workflow covers data loading, EDA, missing-value and duplicate checks, categorical encoding, train-test split, feature scaling, and class-imbalance handling via class weights. The network uses two 32-neuron ReLU dense layers and a sigmoid output layer, trained with the Adam optimizer and binary cross-entropy loss.

98.9% test accuracy · 70% fraud recall · 66% fraud F1 · 21/30 frauds caught
